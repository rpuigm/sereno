# Changelog

All notable changes to Sereno are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Initial Rust application foundation, MIT license, and development container.
- Initial dependencies for error handling, serialization, certificate parsing,
  hashing, and date handling.
- CLI help and version information, plus `version`, `doctor`, and `completion`
  subcommands.
- Text and JSON output for informational commands, with CLI tests.

### Changed

- README now documents current CLI usage and the manual release process.
